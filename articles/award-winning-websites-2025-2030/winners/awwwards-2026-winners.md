# Awwwards 2026 Winners and Nominees — Mechanics Sweep

Fourteen 2026 Awwwards case pages read at component level yield thirteen mechanics beyond the parent reference's catalogue, three of the fourteen adding none. Two of the dependencies those mechanics need are absent from the stack the rest of the corpus runs — Rive and Curtains.js — and Web Audio is a capability class the corpus otherwise lacks. What each winner ships, and the stack behind it, follows. One of the fourteen sits outside the 2026 cycle: MindMarket took Site of the Day (SOTD) on 29 Dec 2025 and is carried here for its Rive path-scroll. Archetype labels follow the taxonomy of the parent reference: [Award-Winning Websites — 2025–2030 Reference](../award-winning-websites-2025-2030.md).

Reliability legend: **[TAG]** = from Awwwards technology tags · **[LABEL]** = from Awwwards curated interaction-element labels · **[DESC]** = author description quote · **[UNVERIFIED]** = inference, an implementation detail extrapolated rather than stated. Where a case page and a search summary disagree, the case-page value is the one reported. Case pages read 2026-07-16.

## Mechanics not already catalogued

Each: mechanic → site(s) → how it works → feasibility → reliability.

1. **Real-time interactive 3D product model (drag/scroll to inspect)** → GQ&AP, Floema, Oryzo → load a Blender-baked glTF into Three.js/WebGL; pointer-drag orbit or scroll-driven camera rig over a PBR-lit model; hotspots trigger editorial callouts. A lit, navigable object rather than an abstract WebGL gradient or noise surface. → **Three.js/WebGL engine.** → [TAG-reliable: GQ&AP `WebGL+Blender+Gestures`; interaction detail UNVERIFIED].

2. **Scroll-scrubbed *real-time-rendered* WebGL scene (not a video file)** → GQ&AP, Oryzo, Vectr → scroll progress drives camera/animation params on a live-rendered Three.js scene each frame instead of seeking a pre-encoded video. Sharper than a scrub-video: arbitrary depth-of-field, lighting, geometry morph. → **Three.js/WebGL + GSAP/Lenis.** → [semi-reliable: GQ&AP "real-time rendering… single immersive timeline"; UNVERIFIED specifics].

3. **3D→2D→3D dimensional morph transition** → Oryzo → a hero 3D object flattens into a matched 2D editorial image, then re-inflates on scroll — FLIP/match between the WebGL canvas object and a DOM figure, or a shader camera-flatten. → **Three.js/WebGL + GSAP.** → [LABEL-reliable: "3D-to-2D-to-3D transition"].

4. **Cursor-reactive GPU particle field** → Oryzo (footer) → instanced particle system whose flow/force responds to pointer position; idle drift when still. → **Three.js/WebGL** (or 2D canvas for a lighter port). → [LABEL-reliable: "footer interactive particles"].

5. **Curtains.js DOM→WebGL plane distortion** → Indigo → Curtains.js binds `<img>` elements to WebGL planes and applies vertex/fragment shaders driven by scroll velocity or hover (ripple, wave, RGB-shift). Lighter than full Three.js; keeps DOM semantics. → **Curtains.js (small WebGL lib).** → [TAG-reliable: `Curtains.js`; distortion behavior is the library's defined function].

6. **Per-chapter Web Audio scenes (sound-reactive narrative)** → Indigo, 21hrs, GQ&AP → gesture-unlocked Web Audio; each scroll section crossfades its own ambient stem; optional AnalyserNode drives visual intensity. New capability class — no audio mechanic appears elsewhere in the corpus. → **Vanilla Web Audio API.** → [DESC/TAG-reliable: Indigo "each with its own sound"; crossfade impl UNVERIFIED].

7. **Draggable/zoomable spatial map with hotspot annotations** → 21hrs (moon) → large annotated surface (flat tiles or WebGL globe) with drag-pan + wheel-zoom inertia; hotspots open timed content. Two-axis free navigation, against the single axis of a pinned horizontal filmstrip. → **Vanilla JS pan/zoom for flat; Three.js for globe.** → [semi-reliable live + `WebGL/3D` tags; drag/zoom specifics UNVERIFIED].

8. **Playable in-page WebGL mini-game** → Lacoste Ace Breaker → real-time game loop, paddle/ball physics + collision, live score, prize/leaderboard hook, keyboard + touch controls, fullscreen canvas. → **Three.js/WebGL + game loop.** → [DESC+TAG-reliable: "break bricks", `Three.js`, cats Games/Fullscreen].

9. **Scroll-driven Rive state-machine animation along a path** → MindMarket → Rive web runtime (`@rive-app/canvas`); scroll progress feeds a Rive state-machine input so a vector character animates/advances along a path. Against scrub-video: interactive states, tiny filesize, resolution-independent. → **Rive runtime + scroll listener** (a dependency outside the GSAP / Three.js stack the rest of the corpus runs on). → [LABEL-reliable: "Path scroll with Rive animations"].

10. **Sticky stacked cards (pin + scale pile on scroll)** → MindMarket → `position: sticky` cards accumulate at a pin point; each incoming card scales/offsets the pile beneath (depth stack). Not catalogued elsewhere in the corpus. → **CSS sticky + GSAP** (near-vanilla). → [LABEL-reliable: "Cards stack on scroll"].

11. **Multi-plane parallax diorama with hidden-layer reveal** → The Renaissance Edition → depth-separated illustrated layers move at differing rates; a concealed layer is unmasked on scroll/hover (peel or clip). Richer than a single clip-path reveal: multi-plane depth plus concealed content. → **GSAP + Lenis** (2D) or **WebGL** for depth blur. → [LABEL+TAG-reliable: "Hidden Layer" + `Parallax`; diorama depth UNVERIFIED].

12. **Infinite draggable WebGL image-plane gallery** → Julien Calot → endlessly looping large image planes in WebGL with drag inertia and velocity-based mesh distortion; wraps without a seam. Distinct from a finite pinned filmstrip. → **Three.js/WebGL** (or transform-loop vanilla). → [TAG-reliable: `WebGL, Infinite Scroll, Gallery`; distortion UNVERIFIED].

13. **Playful character hover state (spring/squash reaction)** → MindMarket → hovering an illustrated character fires a Rive state or GSAP spring (squash/wiggle/eyes-follow). Character-state rather than an image-zoom hover. → **Rive or GSAP** (vanilla-ish). → [LABEL-reliable: "Playful hover interaction"; overlaps the catalogued image-hover — lower novelty].

## What the sweep adds

- **Highest-novelty, best-evidenced new mechanics** (all from reliable Awwwards LABELs/TAGs, not inference): #3 3D→2D→3D morph (Oryzo), #4 cursor-particle footer (Oryzo), #5 Curtains.js plane distortion (Indigo), #8 playable WebGL game (Lacoste), #9 Rive path-scroll (MindMarket), #10 sticky stacked cards (MindMarket).
- **Two external dependencies** beyond the GSAP / Three.js / Lenis stack the rest of the corpus runs on: **Rive** (`@rive-app/canvas`) and **Curtains.js**. Both are small and drop-in.
- **Web Audio (#6)** is a whole capability class the corpus otherwise lacks — cheapest to add (vanilla), high perceived-craft payoff on immersive builds.
- **Award-date discrepancies flagged**, not silently resolved: Oryzo, GQ&AP, Renaissance, MindMarket all show a **SOTD** date on their case page while search summaries framed them as **SOTM** (the normal SOTD→monthly-winner promotion). Lacoste and SÉVE read as **Nominee** on their case pages, not SOTD; their "win" framing is UNVERIFIED.
- Evidence base: Awwwards case-page tags plus curated interaction labels (reliable). No browser execution was used on the live SPAs; every extrapolated implementation detail is marked UNVERIFIED.
