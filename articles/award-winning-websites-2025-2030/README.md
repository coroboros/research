# Award Research Corpus

34 reports beneath [Award-Winning Websites — 2025–2030](award-winning-websites-2025-2030.md), July–August 2026: live reads of shipped winners, archetype reports, cross-corpus analysis. The winners share one signature moment per page and a device found on no other site, one easing register carried by a distinct mechanic per element class, and, in the immersive register, hero media that is driven (real-time, scrubbed, or film loop) rather than decorated. The corpus's highest whole-site score is Lusion v3's 8.25 (Awwwards Site of the Day 2 Oct 2023, Site of the Year 2023; [`archetypes/experimental.md`](archetypes/experimental.md)).

Every claim carries a named site with award and date, a value from shipped CSS or JS, a count from a defined corpus, or an explicit negative; measured values are verbatim. Evidence tags are defined once, in every archetype's `## Corpus` legend ([`archetypes/minimalist.md`](archetypes/minimalist.md#corpus)). A report that uses a local scale defines it in its own Corpus paragraph. `## Refuted` and `## Could not verify` appear only when non-empty.
